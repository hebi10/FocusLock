FocusLock 개인정보 처리방침

적용일: 2026년 11월 11일 · 대상: FocusLock 0.3.0 테스트 버전

개발자: 해비(hebi10). FocusLock은 앱 사용 습관을 확인하고 집중 타이머를 체험하는 개발 중인 Android 앱입니다. 이 방침은 현재 구현된 기능을 설명합니다.

기기에서 처리하는 정보와 목적

  • 사용자가 사용 정보 접근을 허용하면 Android가 제공하는 앱별 패키지 식별자, 앱 이름, 사용 시간, 최근 앱 전환 이벤트 등을 기기에서 조회하여 오늘·7일·30일 사용 분석과 리포트를 표시합니다. 기록 범위는 운영체제와 제조사에 따라 달라질 수 있습니다.
  • Android에서 조회 가능한 앱의 요청 권한과 일부 권한의 허용 상태를 기기에서 확인하여 안내합니다. 다른 앱의 권한을 자동으로 변경하지 않습니다.
  • 앱별 목표 시간, 80%·100% 경고 및 매일 적용 설정, 방해 앱·분석 제외 선택, 화면 테마와 온보딩 완료 여부는 앱 전용 기기 저장 공간에 저장합니다. 알림 중복 전송 방지를 위한 기기 내 전송 표시는 약 45일이 지난 항목을 정리합니다.
  • 집중 세션의 식별자, 시작·종료 시각, 설정 시간, 경과 시간, 진행 상태와 기기 재시작 확인 정보, 완료 보상의 경험치·성장 포인트는 기기 내 Room 데이터베이스에 저장합니다. 이 정보로 앱 재실행 시 상태를 복구하고 7일·30일 집중 리포트와 중복 없는 완료 보상을 제공합니다. 정원 배치 선택도 기기에 저장합니다.

서버 수집·제공 및 외부 서비스

현재 앱에는 자체 서버 전송, 회원가입·로그인, 광고, 결제, 이용 분석 SDK가 없습니다. 개발자는 위 정보를 서버로 수집하거나 제3자에게 전송하지 않습니다. Android 사용 기록은 운영체제가 보관하며 앱은 허용된 범위에서 조회합니다. Google Play 등 배포 서비스 자체의 정보 처리는 해당 서비스의 방침을 따릅니다.

권한과 사용자 선택

사용 정보 접근은 사용자가 Android 설정에서 직접 허용하거나 취소할 수 있습니다. 허용하지 않으면 사용 통계 대신 권한 안내가 표시됩니다. 목표 경고를 사용하려면 사용 정보 접근과 알림 권한이 필요합니다. 앱은 필요한 경우 Android 알림 권한을 요청하고 시스템 설정으로 이동할 수 있도록 안내합니다. 목표의 80%·100% 경고는 약 15분 주기의 백그라운드 작업과 앱 재진입 시 확인하여 발송하므로 절전·권한 제한에 따라 늦어지거나 발송되지 않을 수 있으며 정확한 실시간 알림을 보장하지 않습니다. 접근성 서비스, 다른 앱 위 표시, 전체 앱 목록 조회 권한은 요청하지 않으며 다른 앱을 강제로 차단하지 않습니다.

보관과 삭제

집중 세션·보상 DB와 앱 전용 설정은 Android 설정의 앱 데이터 삭제 또는 앱 제거로 삭제할 수 있습니다. 집중 기록과 보상에는 현재 자동 만료 기능이 없으며 사용자가 삭제할 때까지 기기에 남습니다. 앱은 AndroidManifest에서 자동 백업을 비활성화하도록 설정하지만 제조사별 기기 이전·복원 동작까지 보장하지 않습니다. 사용 정보 접근을 취소하면 해당 조회를 중단합니다. FocusLock에서 데이터를 삭제하거나 권한을 취소해도 운영체제가 별도로 보관하는 사용 기록은 삭제되지 않으며, 해당 기록의 보관은 Android 설정과 정책에 따릅니다.
