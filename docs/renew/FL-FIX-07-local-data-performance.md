# FL-FIX-07 — 성능 및 로컬 데이터 관리

## 구현
- Android UsageStatsManager 원본 밀리초·관측 날짜 집계를 유지하고 일별/앱별 합계의 반복 필터링을 한 번의 그룹 인덱싱으로 줄인다. 7일 그래프는 동일 30일 집계의 마지막 7일을 사용한다.
- 알림이 설정되지 않은 경우 불필요한 OS 사용량 조회를 건너뛴다. 기존 15분 주기, 최근 스냅샷 재사용, 당일 전용 조회를 유지한다.
- 목표 기준 이력의 초기화 검사에서 이력 전체를 한 번만 읽는다. 집중 화면, 홈, 리포트의 보상·성과를 Room 트랜잭션의 공통 metrics()에서 조회한다.
- 설정 → 데이터 관리: Android 문서 생성 UI로 사용자가 선택한 위치에 UTF-8 JSON 저장. 별도 저장공간 권한 및 자체 서버 전송 없음. 저장된 목표 설정·변경 이력, 종료된 집중 기록·보상, 정원 배치만 포함. Android OS의 사용 기록, 진행 중 세션, 내부 알림 마커, 임의 preference 키는 제외. 파일 가져오기/복원 기능 없음.
- 목표 이력 삭제는 과거 변경 이력과 비활성 목표 이름만 삭제하고 현재 목표/알림 설정과 중복 알림 방지 마커를 유지한다. 오늘부터 새로운 기준을 시작하며 과거 달성률을 소급 계산하지 않는다.
- 집중 기록 삭제는 Room 트랜잭션으로 종료/중단된 세션과 연결 보상만 삭제한다. 진행 중·일시정지 세션이 하나라도 있으면 삭제하지 않는다. 삭제 후 보상·리포트·정원 해금 상태 갱신.
- 각 삭제 버튼은 별도 확인창을 표시. 실제 데이터 삭제는 사용자가 앱에서 직접 확인한 경우만 실행. 앱 식별자, 기존 Room v1 스키마, 서명, 트랙 보존.

## 검증 게이트
- Android CI 및 API29/35/36 선별 기기 QA: 실제 OS 관측 집계 정합, 격리된 테스트 DB/SharedPreferences에서 내보내기 포함/제외 범위, 목표 이력 삭제 보존, 진행 중·일시정지 보호, 종료 세션 및 보상 삭제, 설정 진입 및 취소 검증.
- 실제 사용자 데이터를 대상으로 테스트하지 않는다. 문서 선택 UI에서 직접 파일 저장과 외부 문서 제공자 오류는 최종 실기기 QA에서 확인.
- 성능 개선은 코드 구조 기준이며 기기별 시간/메모리/배터리 개선 수치를 측정하기 전에는 정량화하지 않는다.
- Play 배포 및 웹 게시 없음.
