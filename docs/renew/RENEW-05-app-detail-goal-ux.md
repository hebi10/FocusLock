# RENEW-05 — 앱별 상세 분석 및 사용 목표 UX

기준: Google Drive RENEW-00, RENEW-01, RENEW-MASTER #41 및 기존 앱 상세·목표 화면 구조.

## 적용 범위
- 앱 상세의 오늘/7일/30일 기간별 사용 시간·실행 이벤트·차트·시스템 권한 경로는 유지합니다.
- 최근 7일/30일과 직전 동일 기간의 해당 앱 사용량을, 양 기간의 모든 날짜에서 Android가 적어도 하나의 앱 사용 기록을 반환한 경우에만 비교합니다. 양 기간 모두 해당 앱의 기록이 있어야 하며 이전 기간 최소 10분, 현재 기간 최소 1분이 필요합니다.
- 관측일 기준이 자료의 완전성을 보장하지 않음을 화면에 명시하고, 근거 없는 0분 추정/비교는 금지합니다.
- 사용 비중은 반올림된 분 합계 대신 원본 foreground 밀리초 기준으로 계산합니다. 확인 불가인 값은 0%로 표시하지 않습니다.
- 기존 SharedPreferences 목표 요일 비트마스크와 80%·100% 알림 설정을 앱 상세에서 읽기 전용으로 표시합니다. 수정은 기존 GoalSheet에서만 진행합니다.
- 목표 변경 이력이 없으므로 과거 목표 달성률·연속 달성일은 계산하지 않습니다. 사용 목표가 강제 앱 차단이라고 표시하지 않습니다.
- 앱 카테고리는 Android 시스템 분류이며 직접 수정 기능이 아직 없음을 명확히 안내합니다.

## 보존 조건
- 신규 DB/SharedPreferences 저장키, 목표 저장·요일 선택·알림 발송 방식, Room 세션, 정원, 앱 ID, 서명, Google Play 워크플로를 변경하지 않습니다.
- RENEW-04 PR #51과 독립적으로 main 6fc72834에 작성한 Draft PR입니다. #51 안전 병합 후 최신 main으로 정합화·동일 SHA 전체 QA를 다시 진행해야 합니다.

## 검증 기준
- 신규 순수 함수 단위 테스트: 요일과 경고 설정, 원본 시간 비중, 7일/30일 비교 결측 및 증감 상태.
- Android 실제 계측 검증: 기존 요일 정책 및 0분 비교 차단.
- Android CI / API36 전체 화면 / API29·35·36 반응형·스크롤·글꼴160% 검증을 통과한 뒤 병합합니다.
- 스토어 이미지·AAB 내부 테스트 업로드는 RENEW-09 최종 승인 전까지 보류합니다.
