# RENEW-04 — 관측된 Android 사용 기록 기반 인사이트

기준: Google Drive RENEW-00 I01~I06, RENEW-01, RENEW-03 main 6fc72834. 본 PR은 Play를 변경하지 않습니다.

## 인사이트 규칙
- I01: 실제 Android OS 앱별 foreground 시간 중 오늘 최다 사용 앱과 원본 밀리초 기준 비중. 전체 사용 기록이 1분 미만이면 표시하지 않음.
- I02: 오늘 실제 UsageEvents로 관측된 시간대 중 5분 이상 사용량이 있는 경우에만 피크 시간대 표시. 이벤트가 누락될 수 있다는 출처 안내 포함.
- I03: 최근 7일 대 이전 7일 앱별 차이 TOP3. 14일 동안 적어도 하루에 하나 이상의 앱 사용 기록이 있는 경우에만 후보를 계산하며, 동일 앱이 양 기간에 관측되어야 함. 이전 앱의 사용 기록은 최소 10분, 이번 기록 최소 1분, 차이는 최소 5분 요구.
- I04: 최근 7일/30일 총 사용량의 이전 동일 기간 대비 변화율. 두 구간 모두 관측일이 있을 때만 계산하며 기준 기간 최소 60분, 절대 변화 최소 5분 요구.
- I05: 최근 7일 ACTIVITY_RESUMED 관측된 실행·전환 이벤트 상위 앱. 미보유 앱 실행 이벤트는 0회로 대체하지 않음.
- I06: 최근 7일 사용량 증가가 15분 이상인 앱 중, 기존 사용 목표가 없는 앱에만 목표 설정을 제안. 사용자 확인 없는 목표 저장이나 차단 금지.

## 데이터 품질과 한계
- OS에서 해당 날짜에 양의 foreground 시간이 관측되었다고 해서 그 날짜의 모든 앱 이용 이력이 완전하다는 뜻은 아닙니다. 기간 비교는 관측 기준 참고값으로 안내하며 부분 기록·앱 이벤트 미보유·기간 관측일 부족 시 표시하지 않습니다.
- 원본 사용 시간과 이벤트는 기기 내부 Android API만 사용합니다. 런타임 가짜 수치나 신체·정신 건강 진단은 추가하지 않습니다.
- I03/I04 데이터 품질을 보수적으로 제한하므로 일부 신규 사용자에게는 비교 인사이트가 나오지 않는 것이 정상입니다.
