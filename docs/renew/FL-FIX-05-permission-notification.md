# FL-FIX-05 — 권한 및 목표 알림

- 사용 정보 접근 권한은 앱 복귀 시 즉시 확인, 화면 활성 상태에서 5초 간격 재확인, OS 통계 조회 완료 후 재확인한다. 철회 시 기존 통계를 렌더링하지 않는다.
- 기존 Android 사용 정보 설정/앱 알림 설정/개별 목표 채널 설정에 안전한 fallback을 둔다. 런타임 권한, 앱 알림 차단, 채널 차단, 채널 생성 전 상태 구분.
- WorkManager 15분 주기 유지. 앱별 기존 요일·경고 설정과 하루 중복 방지 키 보존. 전체 앱 목표 경고는 기본 OFF, 명시적으로 선택한 경우에만 80%/100% 경고.
- 원본 밀리초로 목표 임계값 판정. 당일 OS 통계만 조회하거나 현재 UI의 최근 스냅샷 재사용. 누락 기록·권한 철회·채널 차단·날짜/시간대 변화 시 알림 요청하지 않음.
- 알림 요청 기록은 실제 전달 여부를 보장하지 않음. 잠금 화면에서 앱 사용 상세 내용 보호.
- 알림의 고유 immutable PendingIntent는 해당 앱 상세(실제 접근 가능한 데이터 및 활성 목표) 또는 전체 목표 관리로 이동한다. 온보딩 및 진행 중인 집중 세션을 중단하지 않는다.
- 기존 데이터·Room·서명·패키지·배포 동작 유지. 새 민감 권한 없음. JUnit, 실제 OS 권한 거부/허용, 고유 알림 타깃, 목표 관리 화면 연결 QA 보강.
- 실제 시스템 알림 전달/채널 설정 복귀/제조사 절전/실기기 테스트는 최종 QA에서 별도 확인. Play 변경 없음.
