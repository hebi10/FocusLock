# FL-FIX-03 — 집중 타이머 시간·보상 정합성

- Room v1 스키마, 데이터베이스 파일, 보상 및 저장 키를 보존한다.
- 실행 중 저장 체크포인트를 계산된 정수 초만큼 전진시켜 매 저장 시 발생하던 소수 밀리초 누적 손실을 제거한다. 의도적 일시정지에서는 표시 단위인 완성 초로 정지한다.
- UI 타이머와 DB 완료 판정은 동일한 단조 시계·밀리초 계산을 사용한다.
- 화면 비활성 상태에서는 UI 틱을 중단하고 복귀 시 같은 세션의 시간을 재계산한다. 앱이 종료된 상태에서 정확한 시점의 완료 알림을 보장하거나 새 권한을 요청하지 않는다.
- 조기 자동 완료 요청은 STOPPED로 저장하지 않고, 일시정지/재부팅 상태에서는 자동 완료하지 않는다. 기존 완료 보상 idempotency와 중복 세션 보호 유지.
- 기존 Room 재오픈·중복 보상·재부팅 계측에서 59회 비정수 체크포인트, 복구 직후 1ms 미달 자동 완료 거부, 정확한 목표 도달 1회 보상을 검증한다.
- 실제 화면 잠금, 앱 강제 종료, 프로세스 재시작·폴더블 환경 계측 및 CI 확인 전 병합 금지.
