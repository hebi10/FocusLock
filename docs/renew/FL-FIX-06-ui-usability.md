# FL-FIX-06 — 화면 및 사용 편의성

- 리포트에서 7/30일 날짜별 실제 관측 사용량을 이전/다음 버튼으로 선택. 기록 미확인과 실제 값의 구분 유지. 월간 막대 간격 조정, 기존 눈금과 검증 태그 유지.
- 분석과 상세 차트는 접근성 선택 상태를 제공하고, 조회 가능한 앱 아이콘을 홈/리포트/분석/상세/목표 시트에 공통 적용. 아이콘 조회는 IO에서 실행하며 실패 시 기존 심볼 사용.
- 분석/리포트 탭 상태를 SaveableStateHolder로 유지하여 상세 화면 복귀 시 기간/검색/스크롤 상태 보존. 화면 재생성 후 앱 ID를 기준으로 실제 통계에서 앱 메타데이터 복구.
- 리포트/상세/설정/권한/목표 관리 화면을 넓은 화면에서 가독성 있는 폭으로 제한. 큰 글꼴에서 분석 2열 전환 조건 보완 및 기간 선택 접근성 개선.
- 기존 디자인 토큰, 앱 식별자, 목표/집중 DB, 권한, 알림 동작 및 Google Play 설정 보존.
- JUnit 날짜 선택 경계, API36 반응형 UI 및 실제 리포트 날짜 변경 검증. 실물 폴더블 기기 및 TalkBack 확인은 최종 QA에 별도 포함.
