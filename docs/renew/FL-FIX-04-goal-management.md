# FL-FIX-04-A — 전체 사용 목표·목표 이력·관리

- 기존 goal.*, goalDays.*, warn80.*, warn100.*, everyday.* 설정과 Room v1을 보존한다.
- 전체 앱 포그라운드 합계 목표는 별도 로컬 설정이다. 전체 목표 알림은 제공하지 않으며 기존 앱별 경고 동작을 그대로 유지한다.
- 홈/설정/리포트에서 목표 관리 진입. 권한 없이 기존 목표 수정·해제 가능. 실제 사용 기록이 없으면 미확인 표시.
- 목표 변경·해제 시 실제 당일 로컬 날짜·시간대·설정 기록을 저장. 기존 목표는 최초 실행일에만 기준 기록을 생성하며 과거 소급 금지.
- 목표 이력이 없거나 변경일/시간대 불일치/관측 기록 부족 시 달성률에서 제외. 오늘은 진행 중으로 제외. 원본 OS 밀리초를 사용하고 달성률 분모는 관측된 날만 계산. 연속 목표 이하 일수는 미확인/초과/변경일에서 끊긴다.
- Android 데이터가 완전하다고 보장하지 않으며, 전체 기기 화면 사용 시간이 아닌 앱별 foreground 합계임을 표시.
- 알림 클릭 시 정확한 앱 상세 연결과 전체 목표 경고 검토는 FL-FIX-05의 권한/알림 작업에서 별도 수행.
- Android CI 및 실제 목표 관리·데이터 보존 계측 전 병합 금지. Google Play 변경 없음.
