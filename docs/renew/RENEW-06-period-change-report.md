# RENEW-06 — 주간·월간 리포트의 실측 기반 변화 요약

기준: Drive RENEW-00/01, GitHub RENEW-MASTER #41. 소스 main 6fc72834. RENEW-04·05 병합 전의 독립 Draft PR입니다.

## 변경 범위
- 7일/30일 화면에서 이전 동일 기간과의 실제 앱별 사용 시간 증감 TOP3를 표시하고 해당 앱의 상세 화면에 연결합니다.
- 사용량 비중 및 증감은 Android OS 원본 밀리초 기준입니다. 기존 단순 비교 문구를 관측일 품질 게이트가 있는 비교로 변경합니다.
- 앱별 비교는 양쪽 기간 모두 같은 앱의 사용 기록이 있고, 양 기간의 모든 날짜에서 하나 이상의 Android 앱 사용 기록이 관측됐을 때에만 활성화합니다.
- 7일 비교에는 14일 관측, 30일 비교에는 60일 관측이 필요합니다. 이전 총합 최소 60분, 앱별 이전 10분 / 현재 1분 및 차이 최소 5분으로 소량 기록의 과장된 변화율을 줄입니다.
- 기록 부족 시 앱별 비교를 표시하지 않고 근거 부족 안내를 표시합니다. OS에서 관측되지 않은 날은 0분으로 처리하지 않습니다.
- 집중 성과는 기존 Room의 완료된 세션만 표시하며 알림/정원/목표 모델을 변경하지 않습니다.
- 날짜별 목표 설정 스냅샷이 없으므로 과거 목표 달성 일수·성공률을 생성하지 않습니다.

## 검증
- JUnit: 신규 앱, 사용자 제외 앱, 양 기간 관측일 부족, 7일/30일 기간, 극단적으로 작은 분모 및 사용량 유지 확인
- Android 계측: 실제 OS 사용 통계에서 관측일을 제거했을 때 증감·변화율이 절대 생성되지 않음 확인
