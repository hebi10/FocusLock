# FL-DESIGN-01 — 최신 생성 시안 구현 및 1:1 검수

기준: 2026-11-25 마지막 생성 이미지(5대 휴대전화, 보라색 강조 UI와 남색 풍경 집중 화면). 이전 Quiet Analytics 흑백 제안과 충돌하는 색은 사용자의 최신 시안 일치 요청을 우선했다. 다섯 페이지는 동일한 앱 화면 비율/시스템 인셋에서 비교한다. 시안의 마케팅 배경, 휴대전화 테두리·상단 광고 문구는 앱 UI에 구현하지 않는다.

- 홈: 실제 오늘 총량, 시간대별 관측 스파크라인, 기존 전체 목표 설정 시 진행률을 상위로 이동, 간결한 실제 앱 순위, 라벤더 인사이트. 실제로 비교 가능한 기간만 변화 표현. 목표 미설정 시 선택 CTA 유지.
- 분석: 보라색 기간 및 그래프, 오늘의 관측 이벤트 연속 구간 선 차트, 카테고리 비중/실제 앱 목록 및 검색·정렬 유지. 24시간 클릭 영역과 가로 스크롤 유지. 기록 미확인은 선으로 연결하지 않는다.
- 리포트: 기존 관측 기준 목표 평가 분모가 있을 때 실제 달성률 링, 7/30일 추이와 날짜 탐색, 사용량/집중 성과 분리. 90일·가상 85% 달성률·가상 집중 변화 그래프를 추가하지 않는다.
- 집중: 시안의 남색 풍경을 장식 벡터로 재해석, 실제 선택 시간과 시작 가능한 재생 버튼, 기존 10/25분·사용자·자유 모드와 시작 버튼, 방해 앱 선택/권한 상태 및 실제 보상 계약 유지. 자동 차단 없음. 5탭을 유지한다.
- 설정: 실제 FocusLock 아이콘·버전 및 라벤더 요약 헤더, 아이콘 메뉴, 기존 권한/목표/테마/데이터/앱 정보, 데이터·알림·기능 범위 설명 보존. 새 계정·구독·알림 설정 페이지·검색 기능을 추가하지 않는다.
- 공통: 라이트 보라색 브랜드/연한 라벤더 표면·카드 경계·보라색 탭, 다크 대비 및 밤 집중 팔레트. 기존 잠금 아이콘, 데이터, 세션, 권한·삭제, API/Play 정책 변경 없음. 실제 통계와 시안 값은 일치시키지 않는다.

검증: Android CI 및 UI-R08 API29/35/36을 기존 계약대로 실행.
