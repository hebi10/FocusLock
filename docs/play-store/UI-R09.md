# UI-R09 — Google Play 스토어 이미지 8장 재제작·업로드

## 목표와 현황
- 대상: `com.haebi.focuslock`, `ko-KR`, phoneScreenshots 8장 (1350×2400 RGB PNG) 및 featureGraphic 1장 (1024×500 RGB PNG).
- **2026-11-11 확인 시점**: UI-R06 PR #26, UI-R07 PR #28, UI-R08 통합 PR #29는 미병합. UI-R08 HEAD `fc904c59c7a4f313ce6fa6220273e373e5ac976f`의 CI/에뮬레이터 QA는 진행 중. 최신 운영 화면을 반영했다고 주장할 수 없음.
- 이 PR은 구형 main 캡처를 새 UI의 스토어 이미지로 오등록하지 못하도록 차단하는 **배포 안전장치**. 8장 생성과 실제 Google Play 업로드의 성공을 의미하지 않음.

## 디자인·소스 불변 원칙
- 사용자 승인 디자인: 중성 화이트·블랙·회색 계열, 2D/평면 이미지, 3D·화려한 배경·그라데이션 없음.
- 홍보 문구는 실제 이미지 밖에만 배치. 앱 내부 수치/화면/사용 기록을 조작하거나 가상의 사용 시간을 추가하지 않음.
- 실제 에뮬레이터 캡처 API36 1080×2400 PNG에서 렌더링. 기존 `scripts/store/render_images.py` 8장 매핑, 원본/출력 SHA256, 이미지 크기·모드·순서 검증을 활용.
- 주요 화면: 홈, 사용 분석, 앱 상세, 목표 설정, 집중 진행, 집중 결과, 정원, 리포트.
- 자동 앱 차단·방해 앱 감지 기능은 실제 구현·검증되지 않았으므로 홍보에 추가하지 않음.

## 필수 게이트
1. UI-R06/07/08 선행 PR의 코드·기능 검증, 올바른 순차 병합 및 **최신 main에서 Android CI와 API36 에뮬레이터 QA 성공**.
2. `store-01-images.yml`은 현재 main SHA와 **정확히 동일한 성공한 emulator QA 실행**에서만 캡처 선택. 구형 성공 실행은 무조건 차단.
3. 실제 캡처가 최소 23장이고 기존 8개 이름의 PNG가 존재하며 각 파일의 1080×2400 PNG 무결성 확인.
4. 렌더 8장·대표 이미지 1장, SHA256 manifest, 실화면과 홍보 문구 일치, 시각적 품질 및 민감 정보 점검.
5. 미검증 이미지 또는 상태에서 업로드 금지. `mode=check` 검증 후 승인된 `main`의 `mode=upload` 또는 소유자 명령으로만 진행.
6. Play API는 한국어 휴대전화 이미지와 대표 그래픽만 변경. 아이콘·AAB·앱 버전·release track·다른 언어 등록정보 수정 금지.
7. Play edit commit 후 **새 edit readback에서 이미지 순서와 SHA256 검증**, 별도로 Console 심사·노출 확인.
