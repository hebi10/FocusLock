# STORE-02-A — FocusLock 첫 2장 Google Play 설명 이미지 시안

작성일: 2026-11-11
상태: **시안 검수용 · Google Play 등록 대상 아님**

## 제작 기준

- 기존 STORE-01 결과물은 Google Play에 유지하며 자동 교체하지 않습니다.
- 실제 Android API 36 계측 테스트 캡처를 사용합니다. 앱 화면 내부의 글자·수치·메뉴·차트 데이터를 생성하거나 수정하지 않습니다.
- 휴대전화 스토어용 1350×2400 RGB PNG 2장, 비교 미리보기 JPG 1장, SHA-256 명세 JSON 1개.
- 기존 FocusLock 아이콘과 브랜드 파란색을 유지하고, 검정·흰색·중성 회색을 기본으로 사용합니다.
- 외부 홍보 카피와 정보 표시는 앱 화면 밖에 배치합니다. 장식용 3D 기기, 가상의 사용 기록, 차단·즉시 알림 등 구현하지 않은 기능 표현은 금지합니다.

## 01 사용 습관 관리

- 카피: **나의 스마트폰 사용, 이제는 알고 쓰세요.**
- 보조 설명: **오늘의 사용 시간부터 자주 쓰는 앱까지 한 화면에서 확인하세요.**
- 레이아웃: 크고 명확한 2행 제목, 3개 기능 안내 레일, 1개 실제 홈 화면을 화면 우측에 크게 배치.
- 실제 캡처: `14-home-granted.png`.

## 02 기간별 사용 분석

- 카피: **오늘 · 7일 · 30일 / 사용 패턴을 기간별로 확인하세요.**
- 보조 설명: **기기에서 확인 가능한 사용 기록을 기간에 따라 다르게 분석합니다.**
- 레이아웃: 어두운 배경의 큰 타이포그래피, 오늘·7일 실제 분석 화면 비교, 기능 구분 태그.
- 실제 캡처: `15-analysis-today.png`, `16-analysis-week.png`.
- 30일은 실제 앱에서 선택 가능한 기간입니다. 시안에서 30일 화면을 임의로 제작하지 않습니다.

## 진실성 및 검수 메모

현재 에뮬레이터 캡처는 기기 사용량이 1분인 검증 환경입니다. 마케팅용 사용량을 임의 합성하지 않았으며, **STORE-02-B에서 실제 검증 가능한 시드 사용 기록/캡처가 준비되면 데이터 표현을 재평가**합니다. 다른 앱 사용을 강제로 차단하거나 실시간 알림을 보장한다고 표현하지 않습니다.
