# UI-R06 — 집중·보상·정원 개선

2026-11-11 · `com.haebi.focuslock`

## 구현 범위
- 집중 설정의 10분·25분·사용자 지정·자유 모드 유지. 방해 앱 선택 시트는 실제 Android UsageStats 기록에 있는 앱만 표시하며 선택 상태를 기존 SharedPreferences `distraction.<id>`에 저장한다.
- 실제 다른 앱 차단·실시간 감지·실패 판정은 구현하지 않는다. 사용 통계 권한이 없어도 집중은 시작 가능하다.
- 실행 중 중복 시작은 UI와 Room 저장소에서 모두 방지한다. 중단 확인 다이얼로그는 실제 경과 시간과 보상 조건을 표시한다.
- 완료/중단 결과는 Room `FocusFinish.reward`에 기록된 정확한 XP/포인트만 표시한다. 저장된 경험치와 포인트 합계를 정원에서 조회한다.
- 정원은 새싹/꽃밭/나무/벤치에 따라 실제 2D Compose Canvas 장식을 표시한다. 아이템 선택 시 즉시 배치되며 `placed_garden_item_id`에 보관한다. 구버전 이름 값 `placed_garden_item`을 읽는 호환 경로를 유지한다.
- 기존 XP 해금 기준(0/60/150/300)을 유지한다. 성장 포인트는 누적 성과로 표시할 뿐 이 단계에서 차감하거나 별도 상점 기능을 만들지 않는다.
- 기존 Room schema version, 서명, 앱 ID, 버전 코드, Google Play 스토어 이미지·트랙 변경 없음.

## 자동 검증
- Android CI: Kotlin/Compose 컴파일, JUnit, Lint, APK 생성
- API36 화면 QA: 기존 37장 + R04 5장 실화면 및 집중 설정→중단→결과→정원 진입 회귀
- Room: 집중 중 중복 시작, 12초 조기 중단 보상 0, 정상 완료 보상 경험치 30/포인트 20, DB 재오픈, 재부팅 안전 일시정지
- JVM: 기존 아이템 이름/ID 마이그레이션, 해금 기준, 잠긴 아이템 배치 방지
